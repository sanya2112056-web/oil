# 🛢️ Oil Signal Bot — Telegram-бот сигналів по нафті Brent

Бот аналізує новини з 6+ джерел, рахує scoring кожної новини та надсилає торгові сигнали по нафті Brent у Telegram.

---

## 📋 Що вміє бот

| Команда | Що робить |
|---------|-----------|
| `/start` | Запустити бота, показати меню |
| `/signal` | Отримати поточний сигнал вручну |
| `/check` | Перевірити статус кожного API окремо |
| `/news` | Топ-5 впливових новин зараз |
| `/stats` | Статистика роботи бота |
| `/help` | Довідка |

**Автоматичні режими:**
- 🔄 Сканування новин кожні 10 хвилин (налаштовується)
- 📅 Event-driven: щосереди після 14:35 UTC — дані запасів EIA США

## 🚀 ПОКРОКОВА ІНСТРУКЦІЯ ДЛЯ НОВАЧКА

### КРОК 1 — Створіть Telegram-бота

1. Відкрийте Telegram, знайдіть бота **@BotFather**
2. Напишіть: `/newbot`
3. Введіть назву бота (наприклад: `Oil Signal Bot`)
4. Введіть username (наприклад: `my_oil_signal_bot`) — має закінчуватись на `bot`
5. BotFather надішле вам **токен** вигляду:
   ```
   7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
   📌 **Збережіть цей токен — він вам знадобиться!**

### КРОК 2 — Дізнайтесь свій Chat ID

1. Знайдіть в Telegram бота **@userinfobot**
2. Напишіть йому будь-що (наприклад, `/start`)
3. Він відповість вашим **Chat ID** (число, наприклад: `123456789`)
4. 📌 **Збережіть це число**

### КРОК 3 — Отримайте безкоштовні API-ключі

> 💡 Мінімум для роботи: лише `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID`.
> RSS-стрічки та EIA (з ключем) покривають 90% сигналів.

#### EIA API (запаси нафти США) — **ОБОВ'ЯЗКОВО**
1. Перейдіть на https://www.eia.gov/opendata/
2. Натисніть **"Register"**
3. Введіть email, ім'я → підтвердіть email
4. Отримаєте ключ вигляду: `abc123def456ghi789`

#### Finnhub — рекомендовано (60 запитів/хв)
1. https://finnhub.io/register
2. Безкоштовна реєстрація → ключ у Dashboard

#### NewsAPI — опціонально (100 запитів/день, є 24-год затримка)
1. https://newsapi.org/register
2. Безкоштовна реєстрація → API Key

#### GNews — опціонально (100 запитів/день)
1. https://gnews.io/ → Sign Up → API Key

#### TheNewsAPI — опціонально (100 запитів/день)
1. https://www.thenewsapi.com/ → Get API key → Free plan

#### Alpha Vantage — опціонально (25 запитів/день)
1. https://www.alphavantage.co/support/#api-key
2. Введіть email → безкоштовний ключ

## ⚙️ Налаштування

### Змінити інтервал сканування
У Railway Variables: `SCAN_INTERVAL_MIN` = `5` (кожні 5 хвилин) або `15` (кожні 15 хвилин)

### Змінити поріг сигналу
`SIGNAL_THRESHOLD` = `70` (суворіше, менше сигналів) або `55` (більше сигналів)

### Додати свої RSS-стрічки
Відредагуйте `config.py`, секція `RSS_FEEDS`:
```python
RSS_FEEDS = {
    "Мій сайт": "https://mysite.com/rss",
    ...
}
```

## 📊 Як читати сигнали

```
🛢️ СИГНАЛ — НАФТА BRENT
📅 31.05.2026 14:32 (UTC+2)
━━━━━━━━━━━━━━━━━━━━
📰 Новина: "EIA: запаси нафти -3.2M barrels"
📡 Джерело: OilPrice.com
━━━━━━━━━━━━━━━━━━━━
🟢 Напрямок: BULLISH — очікується ЗРІСТ
💹 Очікуваний рух: ↑ ~1–2.5%
⏱️ Реакція ринку: 15–30 хв
📈 Таймфрейм: M15 / H1
🔥 Впевненість: 78%
🔑 Тригери: +inventory draw, +drawdown
━━━━━━━━━━━━━━━━━━━━
⚠️ Це не є фінансовою порадою.
```

**Що означає кожне поле:**
- **Напрямок** — BULLISH (чекаємо зріст) / BEARISH (чекаємо падіння)
- **Очікуваний рух** — орієнтовний % зміни ціни
- **Реакція ринку** — через скільки часу після новини очікується рух
- **Таймфрейм** — на якому таймфреймі графіка найкраще видно рух
- **Впевненість** — від 55% (слабкий сигнал) до 95% (дуже сильний)
- **Тригери** — які ключові слова спрацювали (+BULLISH / -BEARISH)

## ❓ Часті питання

**Бот не відповідає:**
- Перевірте змінну `TELEGRAM_BOT_TOKEN` у Railway Variables
- Подивіться логи: Railway → ваш сервіс → вкладка "Logs"

**Команда /check показує ❌:**
- Перевірте що API-ключ введений правильно (без пробілів)
- Можливо, вичерпано ліміт запитів на день

**Бот не надсилає автоматичні сигнали:**
- Перевірте `TELEGRAM_CHAT_ID` — має бути числом
- Переконайтесь що ви написали боту `/start` хоча б раз

**Змінити час EIA-сканування:**
У `bot.py` знайдіть рядок:
```python
jq.run_daily(eia_event, time=dtime(14, 35, tzinfo=timezone.utc), days=(3,))
```
Змініть `14, 35` на потрібний час UTC.
